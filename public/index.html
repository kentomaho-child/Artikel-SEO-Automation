Pengaturan API LLM

Kelola sumber kecerdasan buatan. Pilih antara Mode Gratis bawaan server atau gunakan API Key Anda sendiri tanpa batas.

Endpoint OpenAI-compatible (harus diakhiri tanpa tanda slash).
Contoh: gemini-2.5-flash, llama-3.3-70b-versatile, gpt-4o-mini
API Key Anda hanya disimpan secara lokal di browser Anda (localStorage) dan tidak pernah disimpan ke database.
Tips: Anda bisa mendapatkan API Key gratis dari Google AI Studio (aistudio.google.com) atau Groq Console (console.groq.com).
